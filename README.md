# Fahim's Portfolio

Personal portfolio website built with React, styled in an immersive dark cyberpunk terminal aesthetic. It features an interactive, retro-futuristic terminal command console, a structured academic bento grid showing complete skill matrices, real-time analytics indicators, and a responsive contact system integrated with Formspree.

## Live Demo
https://alif-al-fahim-portfolio.vercel.app/

## Built With
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Framer Motion
